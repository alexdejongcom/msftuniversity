Microsoft University city stickers
==================================
Circular die-cut stickers, 1200x1200 transparent PNG, one per tour city
plus an "Online" badge for remote attendees.
Each shows a city skyline, the MicrosoftUniversity wordmark and the city name.

  sticker-amsterdam.png  Canal houses, the Westerkerk, a bridge and a bicycle
  sticker-berlin.png     Brandenburger Tor, Berliner Dom, Fernsehturm
  sticker-brussels.png   The Atomium and the Grand-Place town hall spire
  sticker-copenhagen.png Nyhavn, Borsen's twisted spire, Rundetaarn, Frederik's dome
  sticker-london.png     London Eye, Big Ben, the Shard, St Paul's, the Gherkin
  sticker-stockholm.png  Stadshuset with the three crowns, Gamla Stan, Riddarholmen
  sticker-athens.png     Acropolis with the Parthenon, Lycabettus hill
  sticker-bergen.png     Bryggen wharf houses, Floyen funicular, fjord ship
  sticker-eindhoven.png  Evoluon, Philips Lichttoren, Strijp-S sheds
  sticker-johannesburg.png  Hillbrow Tower, Ponte City, Carlton Centre,
                         Nelson Mandela Bridge, acacia, mine dumps
  sticker-new-york.png   Statue of Liberty, Chrysler, Empire State, One WTC
  sticker-online.png     ONLINE / THE INTERNET - server racks, cloud, Wi-Fi mast
                         (for attendees who joined a session remotely)
  sticker-orlando.png    Castle, big wheel, palms, rocket launch
  sticker-oslo.png       Holmenkollen ski jump, Opera House, Barcode towers
  sticker-redmond.png    Microsoft campus, evergreens, Mount Rainier
  sticker-zurich.png     Grossmunster, Fraumunster, St. Peter, Alps, lake

Regenerate (also to add a new city) with:
  python3 tools/make-city-stickers.py
Edit the CITIES list in that script to add or restyle a city.

Printing: 1200x1200 prints crisp up to about 10 cm. For larger, raise SIZE
in the script and re-run.
